# Project Management SaaS

A modern **Project Management SaaS** web application built with **React, Vite, TypeScript, Tailwind CSS, and Shadcn/UI**. The application provides a responsive interface for managing projects, users, sprints, tasks, and other project management workflows.

## 🚀 Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Shadcn/UI
- React Router
- Lucide React
- Recharts
- React Hook Form
- Zod
- Axios

## 🔄 Frontend Development Approach

The application is being developed with a **frontend-first approach**.

Dummy data is currently used in frontend modules through `data.ts` where backend APIs are not yet available. This allows frontend features such as:

- Search
- Filtering
- Pagination
- Modals
- Drag & Drop
- Charts
- CRUD UI flows

to be developed and tested independently.

Once the backend APIs are available, the dummy data can be replaced with API responses without changing the overall UI structure.
